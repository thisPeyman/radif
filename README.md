# ردیف

نسخه آزمایشی ثبت و پیگیری سفارش برای فروشگاه‌های اینستاگرامی.

## پیش‌نیازها

- Go 1.26
- Node.js 24 و npm

## راه‌اندازی

```sh
npm --prefix web install
make dev
```

رابط توسعه روی `http://localhost:5173` اجرا می‌شود و درخواست‌های `/api` را به سرور Go روی پورت `8080` می‌فرستد.

## پایگاه داده و داده آزمایشی

پایگاه داده به‌صورت پیش‌فرض در `data/app.db` ساخته می‌شود. متغیر `DATA_DIR` مسیر دیگری را تعیین می‌کند.

برای ساخت یا به‌روزرسانی داده آزمایشی، اطلاعات ورود مدیر را در متغیرهای محیطی قرار دهید و فرمان seed را اجرا کنید:

```sh
SEED_ADMIN_LOGIN=admin \
SEED_ADMIN_PASSWORD='replace-me' \
SEED_ADMIN_NAME='مدیر فروشگاه' \
make seed
```

`SEED_ADMIN_NAME` اختیاری است. اجرای دوباره این فرمان رکورد تکراری ایجاد نمی‌کند.

## ساخت و اجرا

```sh
make run
```

نسخه تولید روی `http://localhost:8080` در دسترس است. برای اجرای بررسی‌های ساخت از `make check` استفاده کنید.
